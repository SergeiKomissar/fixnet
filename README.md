# fixnet

Аварийная кнопка восстановления интернета на macOS. Чинит ситуацию, когда после
переключения или обрыва VPN (либо моргания Wi-Fi / раздачи с iPhone) интернет
пропал и сам не вернулся.

## Возможности

- Диагностирует, **где** разрыв (адрес → шлюз/VPN → интернет → DNS), человеческим
  языком.
- Чинит **адресно** под причину, а не молотит всё подряд:
  - проблема вне ноутбука (мёртвый шлюз / источник) → честно сообщает, не лезет
    в маршруты;
  - завис DNS → перезапускает резолвер без перезагрузки;
  - сбой маршрутов/стека → пересборка маршрутов + DHCP, при необходимости
    передёргивание Wi-Fi.
- Бережёт рабочую сеть: на здоровом соединении ничего не трогает.

## Использование

```bash
./fixnet.sh --check     # только диагностика, без изменений и без root
sudo ./fixnet.sh        # диагностика + починка
```

Для запуска кликом — `fixnet.command` (открывает терминал, спрашивает пароль).

## Установка как кнопки в Dock

```bash
cp fixnet.sh ~/bin/fixnet.sh && chmod +x ~/bin/fixnet.sh
cp fixnet.command ~/bin/fixnet.command && chmod +x ~/bin/fixnet.command
xattr -d com.apple.quarantine ~/bin/fixnet.command 2>/dev/null
```

Затем перетащить `~/bin/fixnet.command` в правую часть Dock.

## Что НЕ делает

Не трогает VPN-клиенты, Tailscale, DNS-серверы и сами utun-интерфейсы; не делает
глобальный сброс IPv6. Подробности и обоснование — в `CLAUDE.md`.
